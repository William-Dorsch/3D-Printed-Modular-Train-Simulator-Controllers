# 3D-Printed-Modular-Train-Simulator-Controllers
Here lies yet another collection of parts to build 3d printed train simulator setups.  Throttles, brakes, switches, dials, thingys, doohickeys, any and controllers I build will be stored here.

## About This Project
It seems the train sim controller market either consists of plasticy, "toy-like" controllers or multi-thousands dollar high end rigs.  It's about time that another option becomes available.  </br>
</br>
I've been building controllers for a little bit over a year now.  My goal has always been to make functional controllers as cheaply as I can.  They weren't great at first, but as my skills have improved, so have the controllers.  </br>
</br>
In this repository, I aim to build a collection of modular control components so anybody with a bit of 3d printing and arduino experience can create their own personalized sim rig without breaking the bank.</br>
</br>
This project is far from perfect.  I'm just a guy with a 3d printer and too much time after all.  But, they are at least a stepping stone for others into the world of making custom sim setups.</br>
</br>
More files and better documentation will be added in the future.  This here is simply the foundation of something I plan to build upon over the next few years. </br>
